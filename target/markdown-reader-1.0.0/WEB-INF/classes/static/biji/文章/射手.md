### **核心原则**

- 经济优先级：**兵线＞野怪＞人头 / 助攻**，核心是通过稳定处理兵线和野怪积累经济，避免因贪人头 / 冲动操作扩大劣势。
- 整体目标：前期稳住个人节奏，中期转向中线扩大发育范围，后期装备成型后跟随队友团战，以 “稳” 对抗逆风，拖至后期翻盘。

### **前期**

**（4 分钟之前）：建立个人节奏，优先保线**

#### 核心任务：

以 “一波兵线 + 一组野怪” 为基础节奏，明确 “兵线优先”，避免漏线或被抓。

#### 具体操作：

1. **清线逻辑**：
   - 能先手清线则先手清（快速掌握线权，为吃野怪 / 支援留时间）；不能则后手清（塔下等待，优先补残血兵，用技能远程清线，避免普攻上前挨打）。
   - 三线交汇时，若敌方中单先清完线可能来抓，需提前预判，避免贪线被包夹。
2. **野怪处理**：
   - 清完兵线后有时间再吃野怪（优先自家野，队友在时可尝试反对面野），牢记 “兵线＞小野”，不贪野怪导致漏线。
3. **不同场景应对**：
   - 辅助未跟随 / 敌方为两人：塔下守线，依托防御塔清线，不贸然出塔，优先保状态（防止被越塔）。
   - 辅助跟随（二打二）：观察辅助是否先手 —— 辅助不上则按单人方式处理；辅助上前则攒技能清前排兵，再用技能清后排兵，专注跟伤害（留人交给队友）。
   - 面对长手法辅 / 压制强的对手：后手清线，等兵线进塔后处理，不被消耗状态（避免因状态差无法清线）。

### **中期**

**（4-9 分钟）：转向中线，扩大发育范围**

#### 核心任务：

从边路转向中线，以 “一波中线 + 一波边线 + 野怪” 为节奏，主发育、副跟团，目标是 9 分钟出核心装备（如破晓）。

#### 具体操作：

1. **转线时机**：
   - 对线劣势：4 分钟清完最后一波兵线转中路；对线优势：5 分钟清完最后一波兵线转中路。
2. **清线与发育优先级**：
   - 以中线为核心：能先手清中线则先手清（清完可快速接边线），否则后手清；清线后若时间充裕，去边路接边线；来不及则用中路附近野怪补充经济（抵消边线损失）。
   - 核心装备目标：优先出 “影刃 + 无尽 + 破晓” 三件套，不因团战耽误发育节奏。
3. **团战与支援**：
   - 主发育、副跟团：仅在队友创造明确留人机会时 “蹭伤害 / 人头”，不主动挑事或强求团战（尤其逆风局，避免因团战失败扩大劣势）。
   - 战略点保护：逆风局可放弃边一塔，但需尽力保住中一塔（防止视野和活动范围被压缩）。

### **后期**

**（8 分半以后）：装备成型，跟随队友团战**

#### 核心任务：

依托前中期积累的经济，在装备成型后（两件半左右），从 “个人发育” 转向 “团队配合”，利用经济优势在团战中发挥作用。

#### 具体操作：

1. **装备标准**：8 分半后需拥有两件半装备（如末世 + 影刃 + 穿云弓），具备团战输出能力。

2. 团战逻辑

   ：

   - 不主动开团，跟随队友行动，聚焦 “中线 + 队友”，团战开启后再进场输出。
   - 若处于优势，可提前跟团滚雪球（推塔、控资源）；若逆风，稳住节奏等待队友，利用装备优势在后期团战中翻盘。

### **关键补充**

- 辅助配合：辅助需在前排提供视野 / 压力，射手需根据辅助状态调整清线节奏（辅助弱势则更保守，辅助强势则可借压力优先清线）。
- 小地图意识：行动前观察小地图，预判敌方动向（如敌方中单是否来抓、辅助位置），避免盲目操作被抓。
- 心态调整：不因队友指责 / 短期劣势打乱节奏，专注 “兵线 + 野怪” 的核心经济来源，理性判断每一步操作。
