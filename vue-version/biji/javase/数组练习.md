# 2. 求最大值

## 代码模板

java



运行









```
public static int getMax(int[] arr) {
    int max = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}
```

## 图解

假设数组：`[3, 1, 4, 2]`

max = 3

1 < 3 → 不变

4 > 3 → max=4

2 < 4 → 不变

最终 max=4

## 真题

求数组 `{5, 2, 9, 1}` 最大值

答案：9

# 4. 数组求和 & 平均值

## 代码模板

java



运行









```
public static int getSum(int[] arr) {
    int sum = 0;
    for (int num : arr) {
        sum += num;
    }
    return sum;
}

public static double getAvg(int[] arr) {
    return getSum(arr) * 1.0 / arr.length;
}
```

## 真题

数组 `{1,2,3,4}` 和为？平均为？

和：10

平均：2.5

# 5. 线性查找（查找元素索引）

## 代码模板

java



运行









```
public static int search(int[] arr, int key) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == key) {
            return i;
        }
    }
    return -1;
}
```

## 图解

`[2,5,7,9]` 找 7

i=0→2 no

i=1→5 no

i=2→7 yes → return 2

## 真题

查找 8 在 `{3,8,1}` 中的索引

答案：1

# 6. 数组反转

## 代码模板

java



运行









```
public static void reverse(int[] arr) {
    for (int i = 0; i < arr.length / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[arr.length - 1 - i];
        arr[arr.length - 1 - i] = temp;
    }
}
```

## 图解

```
[1,2,3,4]
```

i=0：交换 1 ↔ 4 → [4,2,3,1]

i=1：交换 2 ↔ 3 → [4,3,2,1]

## 真题

反转 `{11,22,33}`

结果：`[33,22,11]`

# 7. 冒泡排序（必考）

## 代码模板

java



运行









```
public static void bubbleSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        for (int j = 0; j < arr.length - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

## 图解

```
[5,3,4,1]
```

第一轮：3 4 1 5

第二轮：3 1 4 5

第三轮：1 3 4 5

## 真题

冒泡排序 `{9,5,7}`

结果：`[5,7,9]`

# 8. 选择排序（必考）

## 代码模板

java



运行









```
public static void selectSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < arr.length; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        int temp = arr[i];
        arr[i] = arr[minIndex];
        arr[minIndex] = temp;
    }
}
```

## 图解

找最小，放到最前面

```
[4,2,1,3]
```

i=0 找到最小 1，交换 → [1,2,4,3]

i=1 找到最小 2，不变

i=2 找到最小 3，交换 → [1,2,3,4]

## 真题

选择排序 `{6,2,8}`

结果：`[2,6,8]`
