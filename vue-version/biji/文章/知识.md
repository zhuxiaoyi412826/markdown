# 3D 模型格式

OBJ：是一种简单的文本格式，用于表示三维几何数据。它包含顶点、面、纹理坐标等信息，常用于 3D 建模和动画软件之间的交换。
FBX：是一种多功能的文件格式，广泛应用于游戏开发、动画制作等领域。它可以包含丰富的信息，如模型的几何数据、材质、动画、骨骼等。
GLTF/GLB：是一种基于 JSON 的轻量级格式，适用于 Web 和移动应用中的 3D 模型展示。GLTF 是文本格式，而 GLB 是二进制格式，在加载和传输方面更高效。
STL：最初用于快速成型和 3D 打印，它只包含模型的三角面片信息，结构简单，常用于工业设计和制造。
PLY：是一种多边形文件格式，支持多种数据类型，可用于存储复杂的几何模型，包括顶点、面、边等信息。
3DS：是 3D Studio Max 软件的原生格式，包含模型的几何数据、材质、灯光等信息，曾经在游戏开发和建筑设计等领域广泛使用。
2D 模型格式
SVG：是一种基于 XML 的矢量图形格式，用于描述二维图形和动画。它具有分辨率无关性，无论如何缩放都不会失真，常用于网页设计、图标制作等领域。
PNG：是一种常用的位图图像格式，支持透明背景，适用于存储 2D 图像，如游戏中的角色纹理、界面元素等。
JPEG：是一种有损压缩的位图图像格式，常用于存储照片和复杂的图像，但不支持透明背景。
PSD：是 Adobe Photoshop 的原生格式，保留了图像的图层、通道、蒙版等编辑信息，方便进行后期修改和调整，常用于平面设计和图像编辑。
其他模型格式
USD：是皮克斯公司开发的一种通用场景描述格式，用于在不同的 3D 软件和工具之间进行数据交换和协作，在电影制作和虚拟现实等领域有广泛应用。
DAE：也称为 Collada 格式，是一种基于 XML 的格式，用于在不同的 3D 应用程序之间交换模型、动画和场景数据。
URDF：主要用于机器人领域，用于描述机器人的结构、关节、连杆等信息，以便在模拟和控制机器人时使用。

# Markdown 语法

是一种轻量级标记语言，语法简洁易懂，以下是一些常用的 Markdown 语法：

1. 标题
在文本前加上对应数量的 # 来表示不同级别的标题，从一级标题到六级标题，# 数量越多，标题级别越低。
markdown
## 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
2. 段落与换行
普通文本直接书写即可形成段落，段落之间使用空行分隔。若要进行换行，可以在行尾添加两个或以上的空格后回车。
markdown
这是一个段落。

这是另一个段落。

这一行结尾添加了两个空格  
所以这里换行显示
3. 列表
无序列表：使用 -、+ 或 * 开头，后面紧跟一个空格，然后书写列表项内容。
markdown
- 列表项1
- 列表项2
- 列表项3
有序列表：使用数字和 . 开头，后面紧跟一个空格，然后书写列表项内容。
markdown
1. 第一项
2. 第二项
3. 第三项
4. 强调
加粗：在要加粗的文本前后各添加两个 * 或 _。
markdown
**这是加粗的文本**
__这也是加粗的文本__
斜体：在要倾斜的文本前后各添加一个 * 或 _。
markdown
*这是倾斜的文本*
_这也是倾斜的文本_
加粗并倾斜：在要处理的文本前后各添加三个 * 或 _。
markdown
***这是加粗并倾斜的文本***
___这也是加粗并倾斜的文本___
5. 引用
在段落前添加 > 来表示引用内容，可嵌套使用多个 > 表示不同层级的引用。
markdown
> 这是一个引用。
>
> > 这是嵌套的引用。
6. 代码
行内代码：使用反引号 ` 包裹行内代码。
markdown
这是一个行内代码示例：`print("Hello, World!")`
代码块：使用三个连续的反引号 ``` 或三个连续的波浪线～～～包裹代码块，可在开头的反引号或波浪线后指定代码语言。
markdown

    print("Hello, World!")

10. 表格
使用 | 来分隔不同的单元格，使用 - 来分隔表头和表体，可使用 : 来设置单元格内容的对齐方式。
markdown
| 表头1 | 表头2 | 表头3 |
| :----: | :----: | :----: |
| 单元格1 | 单元格2 | 单元格3 |
| 单元格4 | 单元格5 | 单元格6 |
